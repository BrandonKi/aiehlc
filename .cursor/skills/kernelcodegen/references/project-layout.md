# Project layout (kernel paths from repo root)

Paths for generating and compiling AIE kernel code. Resolve from repo root.

## Unitest (generates kernel.cc)

| Item | Path |
|------|------|
| Unitest directory | `src/mlir/mlirfront/tilinglinalg/pass/unitest` |
| Unitest build | `src/mlir/mlirfront/tilinglinalg/pass/unitest/build` |
| Unitest binary | `src/mlir/mlirfront/tilinglinalg/pass/unitest/build/test` |

Run from unitest dir: `cd build && make`, then `./test` (e.g. `./test dfschedule`). Writes `worklocal/host.cc` and `worklocal/kernel.cc`. `worklocal/compute_kernel.cc` is **pre-existing** (not generated by the unitest).

## Worklocal (kernel sources and compile)

| Item | Path |
|------|------|
| Worklocal directory | `src/mlir/mlirfront/tilinglinalg/pass/unitest/worklocal` |
| Generated kernel | `src/mlir/mlirfront/tilinglinalg/pass/unitest/worklocal/kernel.cc` |
| Compute kernel (pre-existing, hand-written) | `src/mlir/mlirfront/tilinglinalg/pass/unitest/worklocal/compute_kernel.cc` |
| Kernel compile script | `src/mlir/mlirfront/tilinglinalg/pass/unitest/worklocal/compile_kernel.sh` |
| Kernel ELF output | `src/mlir/mlirfront/tilinglinalg/pass/unitest/worklocal/build/kernel` |
| AIE2PS project file | `src/mlir/mlirfront/tilinglinalg/pass/unitest/worklocal/aie2ps.prx` |

Run `compile_kernel.sh` from worklocal after generating kernel.cc.

## Codegen (for bug fixes)

| Item | Path |
|------|------|
| BlueprintToScheduleKernel pass | `src/mlir/mlirfront/tilinglinalg/pass/passblueprinttoschedulekernel/` |
| DfscheduleToKernelApi pass | `src/mlir/mlirfront/tilinglinalg/pass/passdfscheduletokernelapi/` |
| Unitest driver (writes kernel.cc) | `src/mlir/mlirfront/tilinglinalg/pass/unitest/test.cpp` |

Kernel C++ is emitted via emitc from the kernel module after DfscheduleToKernelApiPass; test.cpp writes it to worklocal/kernel.cc.
